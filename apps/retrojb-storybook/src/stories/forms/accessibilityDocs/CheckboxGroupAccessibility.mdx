# CheckboxGroup Accessibility

Extracted from `packages/ui/src/components/forms/CheckboxGroup/styles.ts`, plus
the wiring in `CheckboxGroup.tsx`. Each member is a `Checkbox`, so the box,
target size, focus and forced-colors contract is documented on
**Forms/Checkbox/Accessibility** and not repeated here. Ratios are measured with
`checkContrast` from `@retrojb/wcag-a11y-scanner`.

## WCAG Standard and Expectations

| Criterion                    | Level | How the component meets it                                                                     |
| ---------------------------- | ----- | ---------------------------------------------------------------------------------------------- |
| 1.3.1 Info and Relationships | A     | Native `<fieldset>` + `<legend>`: the group and its name are in the markup, not in ARIA        |
| 1.3.2 Meaningful Sequence    | A     | Legend, description, error, then the boxes — the DOM order is the reading order at every width |
| 1.4.1 Use of Color           | A     | A group error is a message, a red border on every box, and `aria-invalid` on every box         |
| 1.4.3 Contrast (Minimum)     | AA    | Legend, description and error text all clear 4.5:1 in both themes                              |
| 1.4.10 Reflow                | AA    | The layout stacks below `sm` and the row wraps, so there is no horizontal scroll at 320px      |
| 3.3.1 Error Identification   | A     | `error` is wired to the fieldset and marks each member invalid                                 |
| 3.3.2 Labels or Instructions | A     | `label` (the legend) is a required prop; `description` carries instructions                    |
| 4.1.2 Name, Role, Value      | A     | The fieldset is a `group` named by its legend; each member is a native checkbox                |

### `required` means "at least one"

Native `required` on a checkbox means that one box must be checked, so copying
it onto every member would demand all of them. The group sets `required` on
every member only while none is checked and removes it from all of them once one
is. The browser's constraint validation then blocks submission until at least
one box is checked, with no custom validity and no submit handler.

The trade-off: the browser's message reads as if the first box itself were
mandatory, and each box announces "required" while nothing is checked. Pair
`required` with a `description` such as "Choose at least one".

### Disabled

`disabled` goes on the `<fieldset>`, which disables every control inside it
natively, composed children included. Each box leaves the tab order.

### Select all

`selectAllLabel` adds a parent checkbox with no `name` and no `value`, so it
submits nothing. It is `mixed` (native `indeterminate`) while some — not all —
enabled options are checked, and it changes only the enabled options. It does
not carry `aria-controls`: support is poor and the relationship is already clear
from position and the indent.

### Known gaps

- **VoiceOver and `aria-describedby` on a fieldset.** NVDA and JAWS read the
  description and error on entering the group; VoiceOver's support is
  inconsistent. Each member also carries `aria-invalid`, so the error state is
  not lost, but the message text may not be read. Needs a manual pass.
- **`form.reset()`** restores each checkbox's DOM state, but the group holds its
  value in React state, so after a reset the boxes and the group can disagree
  until the next change. Reset through the group's `value` instead.

## Aria

| Attribute          | On       | Set when                         | Value                                         |
| ------------------ | -------- | -------------------------------- | --------------------------------------------- |
| `aria-describedby` | fieldset | `error` or `description` present | error id, description id, then the caller's   |
| `aria-invalid`     | members  | `error` present                  | `true`                                        |
| `required`         | members  | `required` and nothing checked   | native attribute, removed once one is checked |
| `aria-hidden`      | `*`      | `required`                       | `true` — the members' `required` is announced |
