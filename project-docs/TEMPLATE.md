## Rules

- Use markdown references at the end of files so updating links is scalable. See
  the [markdown links guide][links-guide]. This applies to URLs and paths.
- If the file has more than 2 h2 headings, create a table of contents.
- Always update the `updated` date when the file is edited.
- If the file is research, always add a citations section after the author
  block.
- Add screenshots when possible.
- Avoid emojis, em dashes and en dashes.
